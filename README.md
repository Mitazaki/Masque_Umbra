# Masque: Umbra

Masque: Umbra is a square dark-theme Masque skin for World of Warcraft with glowing borders and a clean high-contrast frame.

## Features

- Dark square frame with glowing border treatment
- Retail-ready Masque support for bag and item button regions
- Tuned overlays for junk, upgrade, search, and context states

## Requirements

- World of Warcraft retail
- Masque

## Installation

1. Download the latest release zip.
2. Extract `Masque_Umbra` into your `World of Warcraft\_retail_\Interface\AddOns` folder.
3. Restart the game or run `/reload`.
